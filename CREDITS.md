# Автори й ліцензії

Цей прототип побудовано на основі **APEX-UI** — https://github.com/RubenM1990/APEX-UI
(жива демо-версія: https://apex-ui-xi.vercel.app).

- Автор APEX-UI: **Ruben Mouradian — Reznikov Engineering** (https://reznikov-engineering.com).
- Ліцензія APEX-UI: MIT — оригінальний текст збережено у файлі [`LICENSE-APEX-UI`](LICENSE-APEX-UI).

## Що взято з APEX-UI
- Ідея й геометрія ядра-орба (`components/ApexOrb.jsx`, `components/apex-orb.css`): головне кільце з м'яким
  світінням, тонкі зовнішні кільця, перехрестя, хвиля-еквалайзер, хвилі звуку, пунктирні внутрішні орбіти, підпис стану.
- Ідея «сузір'я» агентів (`components/ReasoningWeb.jsx`): пунктирні орбітальні кільця, «доріжки» плати, вигнуті спиці
  від ядра до вузлів агентів, картка агента при натисканні.

## Що змінено
- Переписано з React/Next.js на чистий JavaScript без збірки (для GitHub Pages).
- Без 3D і без постійного циклу `requestAnimationFrame`: частинки й 3D-ядро APEX-UI (three.js) замінено легким SVG/CSS-ядром;
  анімації лише `transform`/`opacity` (у тому числі хвилі звуку — замість анімації атрибута `r`).
- Нова палітра (графіт, срібло, тонке золото, смарагдові іскри — без синього), українські тексти, агенти Джарвіса,
  панелі задач і витрат, голос і текст, кнопка «СТОП».
- Не використано: WebGL-фон і панель-«лампу» з 21st.dev (їхні автори вказані в CREDITS APEX-UI).
