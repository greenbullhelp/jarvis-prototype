# Джарвіс — прототип інтерфейсу

Живе ядро Джарвіса і команда агентів навколо нього. Лише SVG + CSS, без 3D-бібліотек і без збірки.
Зараз працює на **демо-даних**: без ключів і без підключення до сервера.

**Відкрити:** https://greenbullhelp.github.io/jarvis-prototype/

## Що є
- **Ядро в центрі** зі станами: спокій (повільне «дихання»), слухає (хвиля реагує на голос), думає (орбіти крутяться швидше),
  говорить (м'яка пульсуюча хвиля). Натискання на ядро — показати стани по черзі (демо).
- **6 агентів навколо**: Джарвіс (головний), Контролер, Ігровий, Відео, Трейдинговий, Дослідник.
  Натискання на агента — картка зі статусом і поточною задачею.
- **Ліворуч** — задачі, над якими працює Джарвіс, і хто що виконує.
- **Праворуч** — токени за сьогодні, денний ліміт і залишок, вартість кожного агента.
- **Знизу** — кнопка мікрофона і поле для тексту. **«СТОП»** завжди видно вгорі праворуч.

## Продуктивність
- Анімуються лише `transform` і `opacity`; жодного постійного циклу `requestAnimationFrame`.
- Рівень голосу зчитується ~15 разів/с і лише поки увімкнено мікрофон.
- У фоновій вкладці анімації на паузі (`body.paused`); `prefers-reduced-motion` — без анімацій.
- Телефон (вертикально): ядро вгорі, панелі гортаються нижче, поле вводу закріплене знизу.

## Кольори
Усі кольори — CSS-змінні у [`css/tokens.css`](css/tokens.css): графіт, холодне срібло, ледь помітне золото (тонкі лінії
й теплий відблиск ядра), смарагд — лише «жива іскра». Синього немає.

## Запуск локально
```
python3 -m http.server 8080
```
і відкрити http://localhost:8080 (через `file://` модулі не завантажаться).

## Структура
```
index.html          розмітка
css/tokens.css      кольори, шрифти, відступи, тривалість анімацій
css/app.css         розкладка, компоненти, анімації станів
js/stage.js         SVG-сцена: ядро + сузір'я агентів (будується один раз)
js/app.js           логіка: рендер, стани, голос, СТОП, картка агента
js/data/demo.js     демо-джерело даних
js/data/hermes.js   справжнє джерело (поки не увімкнене)
```

## Підключення до справжнього Джарвіса (Hermes) пізніше
Інтерфейс працює з одним контрактом джерела даних:
```
source.snapshot()        → { halted, agents[], tasks[], usage }
source.subscribe(fn)     → fn(snapshot) після кожної зміни
source.send(text, onPhase) → { reply, agent }; onPhase('thinking' | 'speaking')
source.stop() / source.resume()
```
`js/data/hermes.js` реалізує той самий контракт поверх API панелі Джарвіса (`/api/overview`, `/api/tasks`, `/api/chat`,
`/api/stream`, `/api/stop`, `/api/resume`). Щоб увімкнути: розмістити прототип на домені панелі й у `js/app.js`
замінити `createDemoSource()` на `createHermesSource({ base: "" })`. Ключі в браузер не потрапляють — вхід через сесію панелі.
